# 👨‍🍳 Chef Karim - Assistant Culinaire Intelligent

## 📝 Description
Ce projet est un chatbot interactif conçu pour aider les utilisateurs à découvrir des recettes et obtenir des conseils de cuisine. Il utilise l'intelligence artificielle pour générer des réponses personnalisées et conviviales.

## 🛠️ Technologies Utilisées
*   **Framework Web** : Flask (Python)
*   **IA** : API OpenAI (GPT-3.5 Turbo)
*   **Frontend** : HTML5, CSS3, et JavaScript (Fetch API)
*   **Environnement** : Python-dotenv pour la gestion des clés API
*   **Gestion de version** : Git & GitHub

## ⚙️ Configuration et Installation
1. Clonez le dépôt : `git clone [URL-de-ton-depot]`
2. Installez les bibliothèques : `pip install -r requirements.txt`
3. Créez un fichier `.env` et ajoutez votre clé : `OPENAI_API_KEY=votre_cle_ici`
4. Lancez le serveur : `python app.py`
